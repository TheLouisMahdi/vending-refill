# UniCafe | دانشگاه زنجان

پنل مشترک UniCafe دانشگاه زنجان برای ثبت کسری و پیگیری تأمین و شارژ دستگاه‌های وندینگ است. نام محصول و تعداد موردنیاز هر شماره در آن ثبت می‌شود؛ پس از شارژ، تعداد کسری صفر می‌شود و نام محصول باقی می‌ماند. این پنل همچنین فضایی برای ثبت آمار دستگاه قهوه و یادداشت‌های مشترک تیم دارد.
